# training-app

A web app for habits, workouts and training programs (CRASH-B as the first program), with optional Concept2 PM5 integration.

## PM5 test page

`pm5-test/` is a single static page that connects to a PM5 over Web Bluetooth (Chrome on Android or desktop) and sends a workout to it, using [ErgometerJS](https://www.npmjs.com/package/ergometer-js) (Apache-2.0, vendored in `pm5-test/vendor/`).

With GitHub Pages serving the `main` branch, it is at `https://wzzbzz.github.io/training-app/pm5-test/`.
